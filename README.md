# ⏰ Digital Clock — React

A simple and responsive **Digital Clock** built with **React.js**. The clock displays the current time in real-time with a clean and modern user interface.

## ✨ Features

* ⏰ Real-time clock
* 🔄 Automatically updates every second
* 📱 Responsive design
* 🎨 Clean and simple UI
* ⚡ Built with React.js
* 🕐 Displays hours, minutes, and seconds

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/atiqasaif674-art/digital-clock-react.git
```

Go to the project folder:

```bash
cd digital-clock-react
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.
